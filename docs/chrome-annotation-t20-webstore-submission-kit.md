## 2. 简短描述（132 字以内）

## 3. 详细描述（可直接修改后提交）
- `Annota 是一个面向知识工作者的网页批注插件。你可以对任意网页文本进行划词高亮，并为高亮添加评论备注。`
- `核心能力包括：`
- `1) 划词高亮与评论管理`
- `2) Side Panel 集中查看、定位、编辑、删除`
- `3) Windows/macOS 跨端同步`
- `4) 冲突检测与重试（逐条/批量）`
- `5) 用户数据删除能力与基础安全防护`

## 4. 权限说明（用于商店“为何需要这些权限”）
- `storage`: 保存本地高亮缓存、同步队列、用户设置。
- `tabs`: 获取当前标签页 URL 用于页面级注释关联。
- `sidePanel`: 显示注释列表与同步状态。
- `alarms`: 定时触发同步任务。
- `host_permissions (<all_urls>)`: 在用户访问页面注入高亮与评论交互能力。

## 5. 隐私实践声明（商店问卷参考）
- `收集的数据类型`: 账号信息（邮箱）、用户创建的高亮和评论内容。
- `数据用途`: 核心功能实现（存储、跨端同步、冲突恢复）。
- `是否出售用户数据`: 否。
- `是否用于广告`: 否。
- `是否支持用户删除数据`: 是（`DELETE /api/v1/me/data`）。
