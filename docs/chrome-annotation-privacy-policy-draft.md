# Annota 隐私政策（草案）

最后更新日期：2026-02-12

## 1. 我们收集的数据
- 账号信息：邮箱地址、加密后的认证信息。
- 用户内容：你创建的网页高亮、评论、同步事件元数据。
- 设备信息：设备标识、平台信息（用于多端同步）。

## 2. 数据用途
- 提供账号登录与身份验证。
- 保存并同步你的高亮和评论。
- 处理多端数据冲突与恢复。
- 提供数据删除与审计能力。

## 3. 我们不会做什么
- 不出售你的个人数据。
- 不将你的数据用于广告定向。
- 不在未经授权情况下向第三方公开你的高亮与评论内容。

## 4. 数据存储与安全
- 传输层建议使用 HTTPS。
- 认证采用 access token + refresh token。
- 服务端启用基础安全响应头与访问控制。

## 5. 你的权利
- 你可以删除自己的数据。
- 你可通过已登录状态调用：
  - `DELETE /api/v1/me/data`
- 该操作会：
  - 软删除你的注释数据
  - 撤销 refresh token
  - 删除同步事件记录

## 6. 联系方式
- 如需删除账号或反馈隐私问题，请联系产品维护者（发布时替换为正式邮箱）。
